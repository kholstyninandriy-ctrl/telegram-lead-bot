# 🤖 Lead Finder Bot

Telegram-бот для пошуку B2B-клієнтів: знаходить бізнеси через Google Maps,
збирає контакти, оцінює «теплоту» ліда, генерує тексти для дзвінка / WhatsApp /
Instagram / email і веде CRM-нотатник із нагадуваннями.

---

## Швидкий старт

```bash
pip install -r requirements.txt
cp .env.example .env          # і заповни ключі
python main.py
```

Змінні оточення (Replit Secrets або `.env`):

| Змінна | Обов'язкова | Для чого |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ | токен від @BotFather |
| `GOOGLE_API_KEY` | ✅ | Google Cloud → **Places API (New)** |
| `OPENAI_API_KEY` | ⬜ | без нього працює все, крім AI-текстів |
| `ALLOWED_USER_IDS` | ⬜ | твій Telegram ID (@userinfobot) — щоб ботом не користувались сторонні |
| `APIFY_TOKEN` | ⬜ | добір email із сайтів, закритих Cloudflare або зроблених на JS |

Решта налаштувань (ліміти, таймаути, кеш) — у `.env.example`.

> ⚠️ Бот витрачає **твої** платні ключі Google і OpenAI. Якщо не вказати
> `ALLOWED_USER_IDS`, будь-хто, хто знайде бота, витрачатиме твій бюджет.

## Команди

| Команда | Дія |
|---|---|
| `/find_leads` | пошук бізнесів: країна → ніша → місто → кількість (до 60) |
| `/outreach` | AI-повідомлення в WhatsApp для довільного бізнесу |
| `/add_note` | записати результат дзвінку |
| `/notes` | список нотаток (`/notes interested` — фільтр за статусом) |
| `/stats` | конверсія: дзвінки → зацікавлені → угоди |
| `/export` | нотатки у CSV |
| `/export_search` | результати останнього пошуку з email та соцмережами |
| `/delete_note <id>` | видалити нотатку |
| `/diag [url]` | які сервіси підключені; з URL — чому на сайті немає email |
| `/help`, `/cancel` | інструкція, скасування дії |

Під кожним лідом — кнопки: **🎯 Як підійти**, **💬 WhatsApp-текст**,
**✉️ Лист на email**, **📸 Текст в Instagram**, **📷 Ще фото**,
**📝 Записати результат** (одразу створює нотатку по цьому бізнесу).

### Скоринг ліда

Бал 0–100 рахується з того, наскільки бізнес цікавий для холодного продажу
цифрових послуг: свіжість відгуків, робочий статус, наявність телефону/email,
**відсутність сайту** (найочевидніша послуга на продаж), просілий рейтинг і
мала кількість відгуків (є що покращувати). Закриті бізнеси отримують штраф.
Результати пошуку сортуються від найгарячіших — дзвонити можна згори вниз.

### Звідки беруться email

Google Maps пошту **не віддає взагалі** — її можна дістати лише із сайту бізнесу.
Бот робить це у два шари:

1. **Власний парсер (безкоштовний).** Браузерні заголовки, декодування
   Cloudflare email protection (`data-cfemail`), JSON-LD, обфускація
   `info (at) site (dot) com`, обхід сторінок «Контакти» / Impressum.
2. **Apify (платний, опційний).** Вмикається, якщо заданий `APIFY_TOKEN`, і
   тільки для лідів, у яких **є сайт, але email не знайшовся**. Актор
   `vdrmota~contact-info-scraper` заходить справжнім браузером через проксі,
   тож бере пошту там, де перший шар впирається в Cloudflare-челендж або
   JS-рендеринг. Ціна — близько $1 за 1000 сторінок, тобто центи за пошук.

Якщо в бізнесу **немає сайту** — email не існує, і бот прямо пише про це в картці.

Перевірити конкретний сайт: `/diag https://example.com` — бот покаже HTTP-код,
чи є Cloudflare-челендж, що знайшов у HTML, і, якщо Apify увімкнено, спробує
дістати пошту браузером.

### Кеш і квоти

Результати пошуку кешуються в SQLite на `SEARCH_CACHE_TTL_MIN` хвилин
(за замовчуванням 3 години), тому повторний однаковий запит не витрачає квоту
Google. Щоб отримати свіжі дані — зміни нішу або місто.
