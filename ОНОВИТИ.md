# 🔄 Як оновити бота (покроково)

**Головне, що треба розуміти:**
код лежить на GitHub, а працює бот **не на GitHub**, а там, де ти його запустив
(Replit / Railway / твій комп'ютер). GitHub — це склад. Поки код зі складу не
потрапив туди, де бот реально крутиться, нічого не зміниться.

---

## Крок 1. Зрозуміти, де запущений бот

Згадай, де ти натискав «Run» востаннє:

| Що бачиш | Де бот |
|---|---|
| Сайт **replit.com** з зеленою кнопкою Run | Replit |
| Сайт **railway.app** із логами | Railway |
| Чорне вікно терміналу на своєму Mac | Твій комп'ютер |
| Нічого з цього | Напиши мені — розберемось разом |

---

## Крок 2. Оновити код

### 🟢 Якщо Replit

1. Відкрий свій проєкт на replit.com
2. Зліва внизу знайди вкладку **Shell** (чорне віконце з `~$`)
3. Встав туди **одну команду** і натисни Enter:

```bash
curl -sL https://raw.githubusercontent.com/kholstyninandriy-ctrl/telegram-lead-bot/main/update.sh | bash
```

4. Дочекайся напису `✅ Готово`
5. Натисни зелену кнопку **Run** угорі

### 🔵 Якщо Railway

Railway сам підтягує код із GitHub — треба лише натиснути:

1. Відкрий проєкт на railway.app
2. Вкладка **Deployments** → кнопка **Redeploy** (або **Deploy latest commit**)
3. Дочекайся зеленого статусу

Якщо Railway не бачить нових комітів — у **Settings → Source** перевір,
що вибрана гілка `main`.

### ⚫️ Якщо термінал на своєму комп'ютері

У папці з ботом:

```bash
bash update.sh
python main.py
```

## Крок 3. Перевірити, що вийшло

Напиши боту в Telegram:

```
/diag
```

- Відповів **«версія 2.2»** → 🎉 оновилось, усе працює
- Відповів «Не розумію» або мовчить → код **не оновився**, стара версія ще крутиться

## Крок 4. Увімкнути витягування email (опційно, платно)

Частину сайтів закриває Cloudflare — звичайним запитом туди не зайти.
Щоб бот діставав пошту і звідти, додай **один секрет**:

1. Відкрий **console.apify.com** → аватар угорі праворуч → **Settings**
   → **API & Integrations** → скопіюй **Personal API token**
2. Додай його туди, де в тебе лежать інші ключі:
   - **Replit:** зліва значок 🔒 **Secrets** → **New secret**
   - **Railway:** вкладка **Variables** → **New Variable**
   - **Термінал:** у файл `.env`
3. Назва: `APIFY_TOKEN`, значення: твій токен
4. Перезапусти бота

Перевірка: `/diag` має показати
`🕵️ Apify: ✅ vdrmota~contact-info-scraper`

Перевірити конкретний сайт: `/diag https://theramosteam.com`
