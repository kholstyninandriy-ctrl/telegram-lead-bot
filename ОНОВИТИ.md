# 🔄 Як оновити бота в Replit (3 кроки)

## Чому воно не оновлюється саме

Код лежить на **GitHub**. Бот працює в **Replit**. Це два різні місця,
і між ними немає зв'язку — твій Repl ніколи не підключався до цього репозиторію.
Тому скільки б я не писав коду на GitHub, у Replit нічого не змінюється,
поки код туди не перенести. Це і роблять кроки нижче — один раз, однією командою.

---

## Крок 1. Відкрий Shell у своєму Repl

1. Відкрий свій проєкт: **replit.com/@kholstynіnandri/Create-Repl**
2. Угорі праворуч, де рядок вкладок (`Preview`, `main.py`…), натисни **`+`**
3. У пошуку набери **Shell** і вибери його

Відкриється чорне віконце з рядком `~/workspace$`

---

## Крок 2. Встав одну команду і натисни Enter

```bash
curl -sL https://github.com/kholstyninandriy-ctrl/telegram-lead-bot/archive/refs/heads/claude/blissful-thompson-nnc89z.tar.gz | tar xz --strip-components=1 --exclude='.replit' && python -m pip install -q -r requirements.txt && echo "✅ ГОТОВО"
```

Чекай, доки з'явиться **✅ ГОТОВО** (30–60 секунд).

> Твої дані в безпеці: база нотаток `notes.db`, секрети та налаштування Repl
> ця команда не чіпає — їх немає в архіві.

---

## Крок 3. Перезапусти бота

Натисни зелену кнопку **Run** угорі (або **Stop**, потім **Run**).

### Перевірка

Напиши боту в Telegram:

```
/diag
```

| Відповідь бота | Що це означає |
|---|---|
| «🩺 Діагностика · версія бота **2.2**» | 🎉 Оновилось! |
| «Не розумію: /diag» або тиша | Код не оновився — напиши мені, що було в Shell |

---

## Крок 4 (опційно). Увімкнути витягування email із захищених сайтів

Частину сайтів закриває Cloudflare — туди можна зайти лише справжнім браузером.
Цим займається Apify (у тебе вже є акаунт).

1. Відкрий **console.apify.com** → аватар угорі праворуч → **Settings**
   → **API & Integrations** → скопіюй **Personal API token**
2. У Replit зліва натисни 🔒 **Secrets** (значок замка)
3. **New secret**:
   - Key: `APIFY_TOKEN`
   - Value: *(вставлений токен)*
4. Натисни **Run** ще раз

Перевірка: `/diag` має показати
`🕵️ Apify: ✅ vdrmota~contact-info-scraper`

Перевірити конкретний сайт: `/diag https://theramosteam.com`

## Якщо щось зламалось

- У Replit зліва є **History / Checkpoints** — можна відкотити проєкт на будь-який
  момент до оновлення
- Стара версія коду нікуди не зникла — вона в історії GitHub, поверну за хвилину
- Просто надішли мені текст помилки з вкладки **Console** — розберу
